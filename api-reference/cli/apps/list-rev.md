# fal apps list-rev

> List the revisions of your fal applications with fal apps list-rev. Pass an app name to show the revisions of one app, and use --env to choose the environment.

```bash theme={null}
Usage: fal apps list-rev [-h] [--debug] [--pdb] [--cprofile] [--env ENV]
                         [app_name]

List application revisions.

Positional Arguments:
  app_name    Application name (optional).

Options:
  -h, --help  show this help message and exit
  --env ENV   Target environment (defaults to main).
```
